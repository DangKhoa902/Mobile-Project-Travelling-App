# 🌍 Travelling App

Ứng dụng du lịch đa nền tảng (Web & Mobile), cho phép người dùng tìm kiếm địa điểm du lịch, xem thông tin, lưu địa điểm yêu thích và đặt vé theo các gói dịch vụ.

> 🚧 **Trạng thái:** Đang trong quá trình phát triển – chưa phải phiên bản chính thức.

## 🛠️ Technology Stack

### Frontend

- **React Native + Expo** – Phát triển ứng dụng đa nền tảng
- **TypeScript** – Kiểu dữ liệu và an toàn mã nguồn
- **Expo Router** – Điều hướng
- **NativeWind** – Styling
- **Axios** – Giao tiếp API
- **Zustand** – Quản lý state
- **@expo/vector-icons** – Icon

### Backend

- **Node.js + Express** – Xây dựng REST API
- **TypeScript** – Phát triển backend
- **Prisma ORM** – Làm việc với cơ sở dữ liệu
- **MariaDB** – Cơ sở dữ liệu
- **Zod** – Validation dữ liệu
- **JWT + bcrypt** – Xác thực và bảo mật

### Development & Testing

- **Git / GitHub**
- **VS Code**
- **Postman**
- **Android Studio / Android Emulator**
- **Jest / Supertest**

## 📁 Project Structure

## 🚀 Development

### Frontend

```bash
cd fe
npm install
npx expo start
```

### Backend

```bash
cd be
npm install
npm run dev
```
